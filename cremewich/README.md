# Cremewich website

Static one-page site for Cremewich ice cream sandwiches (HTML, CSS and a little JS, no build step).

Preview locally:

```sh
cd cremewich
python3 -m http.server 8000
# open http://localhost:8000
```

Images in `images/` come from Cremewich's brand posts. Prices, hours, the classic flavours and the email address are placeholders to replace with real details.
